An entry for make.fun's [One Line of Earned Pride](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557) bounty ($5 in USDC): a program that writes one line — a quiet, earned moment of pride for someone in a scene.

`main.py` (Python 3.13, standard library only) writes a single line to `/output/entry.txt`. The line is a boy who has fallen off his bike six times before lunch, riding past his own gate with both feet on the pedals — and for the first time that morning, not checking whether anyone is watching. The effort is felt in the six falls, the scene is seen happening, and the pride arrives in the last words as a change inside him, not a trophy. No podium, no medal, no graduation — just a kid who no longer needs an audience. The output is deterministic: every run writes the same line, 182 characters as the gate requires (1–240).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
